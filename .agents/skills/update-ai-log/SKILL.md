# Update the AI Log

1. Read `docs/AI_LOG.md`. If it does not exist, create it with the heading `# AI Log`.
2. Find the section for the current milestone, such as `## Milestone 1`. Create it if needed.
3. Ask which AI tool and model were used, what task was performed, and what the main prompt was.
4. Record the tool, task, actual prompt, what the AI generated, and what was kept, changed, or rejected.
5. Ask whether the AI made a mistake or produced poor code. If so, document what was wrong, how the issue was noticed, and how it was fixed.
6. Never invent prompts, tools, mistakes, or testing results. Ask if anything is unclear.
7. Show the proposed log entry and wait for confirmation before saving changes.
